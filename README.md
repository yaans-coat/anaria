# anaria!
a sick web proxy

[![join the discord!](https://invidget.switchblade.xyz/VPq3CD6d7B)](https://discord.gg/VPq3CD6d7B)

## why should i use it?
- slick ui
- games and emulators from different sources
- built in anime and movies
- cloud sync for syncing browsing data and etc.
- duckduckgo search
- very cool...

## self-hosting
(sorry for linux only support, but i hate windows slop)

```bash
#cloning
git clone https://github.com/yaans-coat/anaria

#setup
cd anaria
bash setup.sh
```
